# Etappe wandelplanner

Web-app om meerdaagse wandeltochten in Europa te plannen: route op de kaart, etappes, hutten en water, weer per dag, en een offline schetskaart voor onderweg.

Open de site in Safari op je iPhone, tik op Deel en kies "Zet op beginscherm".

Kaartgegevens © OpenStreetMap-bijdragers. Routes via BRouter, weer en hoogtes via Open-Meteo.
